# CPP07

## Description
CPP07 introduces C++ templates, one of the fundamental mechanisms for writing generic and reusable code.
The exercises focus on creating function templates and class templates, allowing the same implementation to work with different data types without duplicating code. The module also introduces template specialization and demonstrates how templates interact with the C++ type system.
The goal is to understand how generic programming works in C++ and how templates are used throughout the STL (Standard Template Library).

## Key Concepts
- Function templates — Write generic functions that can operate on different data types.
- Class templates — Create generic classes whose behavior can be adapted to different types.
- Template instantiation — Understand how the compiler generates concrete versions of templates when they are used.
- Generic programming — Avoid code duplication by designing algorithms and data structures independently of specific types.
- Template specialization — Provide a specific implementation of a template for a particular type.
- Non-type template parameters — Use values, rather than types, as template parameters.
- STL connection — Understand the principles behind templated containers and algorithms such as std::vector, std::array, and std::find.
- Compile-time type safety — Templates allow the compiler to detect type-related errors during compilation.
- C++98 templates — Implement generic code while respecting the restrictions and features of the C++98 standard.
